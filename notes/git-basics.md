## The three areas

- **Working directory** — your actual files.
- **Staging area** — what will go into the next commit (`git add`).
- **Repository** — the committed history (`git commit`).

## Everyday commands

```bash
git status
git add <file>
git commit -m "message"
git log --oneline
git diff
```
